# Allkin Integrations

Ready-made integrations for [Allkin](https://allk.in).

An integration adds something to Allkin: a notepad, a terminal, a search engine of your own, a
bridge to Telegram or to Home Assistant, and more.

## Using one

In Allkin, open the **Integrations** page and press **Add**. Pick an integration, read what it
does and what it asks for, then install it.

An integration gets only the rights you grant it, from its page.
